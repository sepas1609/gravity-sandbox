# 🪐 Gravity Sandbox — 2D Rigid-Body Physics Lab

An interactive physical environment simulating multi-body gravity, momentum transfer, and collision dynamics.

## ⚙️ Physics Simulation Mechanics
- **Celestial Environments**: Real-time gravity switching between Earth ($9.81 m/s^2$), Moon ($1.62 m/s^2$), Jupiter ($24.79 m/s^2$), and Zero-G.
- **Matter.js Engine**: Rigid-body collision detection using Gilbert-Johnson-Keerthi (GJK) and Separating Axis Theorem (SAT).
- **Interactive Spawner**: Dynamic creation of circles, rectangles, and static collision deflectors.
